# Client Performance Data

Drop raw weekly numbers here as `CLIENTNAME.md` (any format — notes, pasted numbers, CSV). The reporting agent turns each file into a polished client-facing report under `reports/CLIENTNAME/`.

Example `reports/data/acme-roofing.md`:
```
Week of 2026-08-04
Spend: $850
Leads: 22
Calls booked (AI receptionist): 14
```
